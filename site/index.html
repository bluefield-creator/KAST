CASTER

Arma 3 server management from one web panel.

Install servers and mods from Steam, configure instances, and run and monitor them from the browser.

Download latest View on GitHub

Self-hosted. Runs on Windows, Linux, or Docker. No client install needed.

Everything for your Arma 3 community

Server profiles

Create multiple instances with their own configs, headless clients, restart policies and scheduled start/stop.

Steam downloads

Install and update the Arma 3 server and Workshop mods with a durable queue that survives restarts.

Mod library

One shared library with per-instance load order, presets, local mods and batch updates.

Missions

Upload PBOs, tag and search them, group them into campaigns, and serve them over fast HTTP downloads.

Live monitoring

Host and per-instance metrics, live console tailing, RPT event detection and crash alerts.

Secure access

Local accounts, OIDC (Authentik and others), Windows and Linux system accounts, and API keys.
